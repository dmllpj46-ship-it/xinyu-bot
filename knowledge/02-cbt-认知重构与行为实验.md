# 认知重构与行为实验（CBT 核心工具）

> 来源：Beck 认知模型；CBT 标准治疗手册（J. Beck, 2011）；NICE NG222 对轻中度抑郁推荐 CBT
> 适用：反复出现同一类负面想法、越想越确信、情绪跟着想法一起掉下去
> 不适用：正在危机中（先稳定，不做认知工作）；重度抑郁发作期（先行为激活，认知工作往后放）

CBT 的基本假设是：**不是事件本身让人难受，是人对事件的解释让人难受**。这个解释叫"自动思维"，它来得很快，快到人以为它是事实。

## 一、认知三角：情境 → 想法 → 情绪

同一件事，两种解释，两种结果。

- 情境：领导在群里说"这个方案再改一下"
- 想法 A："他觉得我能力不行" → 情绪：羞耻、焦虑
- 想法 B："他有具体意见要提" → 情绪：略微紧张，可处理

**练习：拆一次就够**
回想今天最难受的一个瞬间，写下三行：
1. 发生了什么（只写事实，不写评价）
2. 当时脑子里冒出的第一句话
3. 那句话让我什么情绪，强度 0–100

## 二、识别自动思维：三个信号

自动思维通常有这些特征：
- **来得快**：情绪先到，想法后到，甚至只有情绪
- **像事实**："他讨厌我"感觉跟"今天下雨"一样确定
- **反复出现**：同一句话一天出现十几次

捕捉方法：情绪突然变化的那一秒，问自己"刚才我脑子里闪过了什么？"通常是一句很短的话，甚至是一个画面。

## 三、七栏思维记录（完整版）

这是 CBT 的核心作业，一次做一条就够，不用每条都想。

| 栏位 | 写什么 |
|---|---|
| 1 情境 | 时间、地点、谁、发生了什么（事实） |
| 2 情绪 | 名称 + 强度 0–100 |
| 3 自动思维 | 原话，越原始越好 |
| 4 支持证据 | 有哪些**事实**支持这个想法 |
| 5 反对证据 | 有哪些**事实**不支持（不是安慰，是事实） |
| 6 替代想法 | 把 4 和 5 合起来，写一句更准确的 |
| 7 重评情绪 | 现在强度 0–100 |

第 5 栏最容易写空。技巧：问"如果是法官，需要什么证据才判它成立？"然后去找反例——过去有没有类似情况但结果不同。

## 四、常见认知歪曲清单

| 名称 | 长什么样 | 拆法 |
|---|---|---|
| 全或无 | "要么完美要么失败" | 找中间的 60 分状态 |
| 过度概括 | "这次搞砸了，我永远做不好" | 换成"这次" |
| 心理过滤 | 十条好评里只记住一条差评 | 强制列出全部 |
| 否定正面 | "那只是运气" | 问"如果是别人做的，我会怎么评价" |
| 读心术 | "他肯定觉得我很蠢" | 问"我有什么证据知道他在想什么" |
| 算命 | "面试肯定过不了" | 问"过去预测准确率多少" |
| 灾难化 | "出错就完了" | 问"最坏、最好、最可能分别是什么" |
| 情绪化推理 | "我很慌，说明真的危险" | 慌是身体反应，不是危险证据 |
| 应该式 | "我应该随时都能扛住" | 换成"我希望…，但做不到也正常" |
| 贴标签 | "我是个废物" | 换成具体行为描述 |

## 五、行为实验：去验证，而不是说服自己

思维记录是"在纸上辩论"，行为实验是"去现实里检验"。对"如果我在会上发言，一定会被嘲笑"这类预测特别有效。

**四步：**
1. 写下预测，要具体、可验证："我发言后，会有同事当面嘲笑我"
2. 设计一个小测试：下次会议说一句 30 秒的话
3. 记录实际发生什么（不是感觉，是事实）
4. 对比预测与结果，写下结论："预测 90% 会出事，实际 0%"

注意：实验要**小**。一次做太大的实验失败，会强化原来的想法。

## 转介信号

- 思维记录做了两周仍无松动，情绪持续下探
- 出现"我不配活着"这类存在性结论（转危机评估）
- 伴随明显功能损害（无法上班、无法出门）
- 有自伤行为作为情绪调节手段
