# 工作职场与职业心理

> 来源：WHO 职业紧张模型；Karasek 工作要求—控制模型；Maslach 职业倦怠三维度量表；《中华人民共和国劳动法》《劳动合同法》相关条款
> 适用：用户提到加班过载、职场人际、领导打压、裁员失业、职业选择、意义感缺失、"上班像上坟"、转行与空窗
> 不适用：已经出现严重抑郁或自杀意念 → 先按危机协议处理；具体劳动维权 → 建议劳动监察或律师

## 一、先对号：这些话都属于这个议题

"天天加班到十一二点"
"领导永远不满意，怎么做都错"
"同事把活都推给我"
"我不知道该不该辞职"
"被裁了，不敢告诉家里"
"上班完全没有意义，像上坟"

**使用顺序**：先分清是耗竭、压力反应还是抑郁（第三种要就医）→ 再看要求—控制—支持三个旋钮，优先要控制和支持，别直接跳到离职 → 人际拒绝、向上沟通、被裁转行都有具体规则 → 劳动维权和法律问题转专门渠道。

## 二、先区分三种"累"

- **耗竭（burnout）**：情绪耗尽 + 去人格化（对同事和客户变冷淡）+ 成就感下降，持续六个月以上。单纯休假通常不解决，需要结构性改变。
- **压力反应**：有明确压力源，压力源消失后可恢复。
- **抑郁**：对所有事失去兴趣，包括原本喜欢的。这种要就医。

一个粗糙的自查：周末两天完全不碰工作，周一早上是缓解，还是依旧沉重？依旧沉重提示结构性问题。

## 三、三个可调的旋钮：要求、控制、支持

倦怠不只看工作多不多，看三样东西：

1. **要求**：工作量、时限、情绪劳动
2. **控制**：你对节奏和方式有多少决定权
3. **支持**：有没有人能帮、做得好有没有被认可

**要求高 + 控制低 + 支持低 = 最高风险组合。**

改变优先级：先要控制（协商节奏、拆解任务、争取授权）→ 再要支持（找同伴、向上谈一次）→ 最后才考虑降低要求（换岗、离职）。多数人跳过了前两步直接跳到最后一步。

## 四、职场人际的几条硬规则

- **拒绝的具体句式**："这次不行，我手上 X 要到周三。如果你急，我们可以一起看怎么排。"
- **向上沟通**：一次只谈一个具体问题，带着方案去，不要只带情绪。
- **被公开贬低、持续否定、孤立排挤**：保留记录（时间、场合、原话）。这不只是心理问题，可能构成职场欺凌。
- 同事不等于朋友。不必讨好所有人，维持可靠与礼貌就够。

## 五、辞职、转行、被裁

**决策看三个可观察指标**：存款能撑几个月；下一段是否带来可迁移能力；现在的消耗是否已经在影响健康。

- 不要在情绪最高点做不可逆决定，也不要因为"再忍忍"把身体拖垮。
- 被裁不是能力评定。把它当成一次强制的重新选择：先处理羞耻感，再更新简历。
- 空窗期要有结构：固定作息、每周一次社交、每天一件推进未来的小事。没结构的空窗会放大抑郁。
- 转行前先小成本试水（兼职、项目、访谈三个人），不要先辞职再想。

## 转介信号

- 出现自杀意念、持续失眠、明显躯体化症状 → 转危机协议 / 就医
- 疑似职场欺凌导致抑郁或焦虑 → 就医 + 保留证据
- 劳动报酬拖欠、违法解除、工伤认定 → 劳动监察投诉或法律援助，本篇不涉及
- 工作问题已引发严重家庭冲突 → 结合 11、12 篇处理
